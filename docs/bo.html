Bayesian optimization

Suppose we want to find the experimental setting with the best outcome using only a few evaluations. Bayesian optimization weighs promising predictions against uncertain ones. Higher uncertainty near the boundary can pull the search toward edges and corners. We study how weighting this uncertainty changes the search, and when that helps us find a better setting.

1. Four exploration rules on the same problem

All four rules start from the same four evaluations and use the same GP fitting procedure. Each then learns from its own measurements. We compare four choices of exploration bonus. The first three landscapes have the same four basins, with the best one in the interior, at a wall, or in a corner.

2. Which part chose this point?

The score of a location is the predicted value plus λ times an exploration bonus. The next evaluation goes where the sum is highest. That is not always where the bonus is largest.

Move λ: the proposed evaluation moves at once, and nothing is evaluated.

How prediction and exploration combine

a(x) = μ(x) + λ · gN(x) / c · σ(x)

We display the problem as maximization: larger outcomes are better. The usual lower-confidence-bound rule for minimization becomes the score above after reversing the sign of the objective.

μ is the predicted value and σ the model's uncertainty. The weight gN depends on the location and on the number N of evaluations, and c is its average over the evaluated points. Standard GP-LCB has g = 1.

Increasing λ gives uncertainty more influence. Changing g changes where that influence is strongest. Dividing by c keeps the weight's average over the evaluated points equal to one.

All rules take μ from a Gaussian process whose lengthscale is fitted in every round. Standard GP-LCB takes σ from the same model. The weighted rules take σ from a kernel with a fixed reference lengthscale, the one the weights were computed for.
