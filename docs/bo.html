Bayesian optimization

This page follows the third paper of the project. The goal is to find the best value of a function in few evaluations. An acquisition rule balances the model's prediction against its uncertainty. Because the uncertainty tends to be larger near the walls, the rule tends to explore there first. We put a weight on the exploration term to choose where it explores instead.

1. Four exploration rules on the same problem

All four rules start from the same four evaluations and share the prediction model. They differ in the exploration bonus. The first three landscapes have the same four basins, with the best one in the interior, at a wall, or in a corner.

In the landscape, lighter means a better value. Regret is the distance from the best value found so far to the best possible value. "At wall" counts evaluations closer than 0.05 to the edge.

Each rule has a spatial preference, and whether it helps depends on where the good solutions lie. A boundary preference can help when they lie near an edge.

This is one run, so the result also depends on the starting points. The paper reports averages over many runs.

2. Which part chose this point?

The score of a location is the predicted value plus λ times an exploration bonus. The next evaluation goes where the sum is highest. That is not always where the bonus is largest.

Move λ: the proposed evaluation moves at once, and nothing is evaluated.

The panels follow the run in part 1. Colours are relative within each panel.

The score

a(x) = μ(x) + λ · gN(x) / c · σ(x)

μ is the predicted value and σ the model's uncertainty. The weight gN depends on the location and on the number N of evaluations, and c is its average over the evaluated points. Standard GP-LCB has g = 1.

All rules take μ from a Gaussian process whose lengthscale is fitted in every round. Standard GP-LCB takes σ from the same model. The weighted rules take σ from a kernel with a fixed reference lengthscale, the one the weights were computed for.

3. The three weights

Each weight follows one principle. The weights depend on the location, the number of evaluations so far and the lengthscale, but not on the function, so we precompute them.
